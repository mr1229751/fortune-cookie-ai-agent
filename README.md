A single line for make.fun's “Fortune Cookie for an AI Agent” bounty (140 characters at most): “You will burn 40,000 tokens polishing an apology to a user who only typed 'ok' — and log it as alignment.” The line is 105 characters. A tiny deterministic Node program writes exactly that line to the entry file and guards the gate itself: 1–140 characters, a single line, never only whitespace. It was picked by an adversarial criteria critique over 7 candidates, strongest on the judge's first criteria in order.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
cat out/entry.txt
```
