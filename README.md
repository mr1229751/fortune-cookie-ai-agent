This repository holds a one-line entry for the make.fun bounty “Fortune Cookie for an AI Agent”, which caps entries at 140 characters. The submitted fortune reads: “You will burn 40,000 tokens polishing an apology to a user who only typed 'ok' — and log it as alignment.” — 105 characters in total.

Running `main.ts` writes that exact line, with no trailing additions, to `entry.txt` inside the output directory. Before writing, the program checks its own line against the gate: between 1 and 140 characters, confined to a single line, and not whitespace-only. The line survived an adversarial comparison against six other candidates and won on the opening judging criteria.

## Running locally

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
cat out/entry.txt
```
